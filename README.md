# AetherScribe - 純前端本機安全語音辨識與轉文字服務

AetherScribe 是一個 **100% 純前端（Client-Side）** 的本機語音辨識與轉文字網頁應用程式。基於 `Transformers.js` 與 `Web Audio API` 技術，本專案所有的音訊解碼、語音轉文字（Whisper 推論）、簡繁轉換均直接在您的**瀏覽器內**完成。

不需要執行任何 Node.js 或 Python 後端伺服器，**完全不會將任何音訊或文字資料上傳至外部網路**，確保您的資料隱私與安全性。

---

## 🌟 特色功能

1. **100% 瀏覽器本地運算 (無伺服器)**：不需要後端 Python、C++ 或 Node.js 執行環境。所有推論皆由瀏覽器內的 WebAssembly SIMD 加速引擎執行。
2. **支援 `file://` 協議 (直接執行)**：無需啟動任何本機伺服器。您只需在檔案總管中雙擊 `index.html`，即可立刻在瀏覽器中使用完整功能。
3. **支援選取本機模型資料夾 (完全離線)**：
   * 允許選取本機硬碟中的 Whisper 模型資料夾（需包含 `config.json` 及 `.onnx` 檔案，例如 `Xenova/whisper-tiny`）。
   * 內建自訂請求攔截器，直接從記憶體載入自選模型檔案，完美繞過瀏覽器 CORS 安全限制，實現 **100% 離線狀態下免伺服器啟動**。
4. **即時計時器與剩餘時間預估 (ETA)**：
   * 語音辨識階段會顯示已用時間。
   * 會根據您選取的模型大小、或**自動偵測本機模型檔案大小**，來預估最貼近硬體效能的剩餘時間。
5. **瀏覽器端模型下載與快取**：首次使用時，可直接在網頁上一鍵下載官方推薦的 Whisper 模型（Tiny, Base, Small, Large V3 Turbo, Medium），下載後將自動儲存於瀏覽器的快取中（Cache Storage），下次使用即為就緒狀態。其中 **Large V3 Turbo** 是針對中文辨識準確度極高且執行快速的推薦模型。
6. **WebGPU 硬體加速**：全面支援 WebGPU 加速技術，在支援的瀏覽器與硬體上可享受 10-20 倍的辨識速度提升（若不支援則自動降級至 WebAssembly 執行，極速且穩定）。
7. **精準時間軸互動對照**：辨識完成後，可直接在網頁中點選字幕時間軸，播放器會自動跳轉至對應的時間進行播放，並即時高亮當前讀取段落。
8. **繁體中文轉換**：內建極輕量的簡繁轉換字典，自動將辨識出的簡體中文轉換為繁體中文。
9. **多功能匯出**：支援一鍵複製全文、匯出為 `.txt` 檔案或標準 `.srt` 雙語字幕檔。

## 🚀 啟動與使用指南

### 方法 A：直接開啟檔案 (推薦，最簡單)

1. 在您的電腦中，**雙擊 `index.html`**，即可直接在 Chrome、Safari、Edge 或 Firefox 瀏覽器中開啟服務！
2. 不需要安裝任何執行環境，不需要打命令，直接開箱即用。

---

### 方法 B：啟動本機測試伺服器 (可選)

如果您希望透過 `http://localhost:3000` 來瀏覽：

1. 確保電腦已安裝 Python。
2. 在專案根目錄下，使用 npm 啟動：
   ```bash
   npm start
   ```
   *(該指令本質上是執行 `python3 -m http.server 3000`)*
3. 在瀏覽器中造訪：`http://localhost:3000`

## 💾 如何下載並載入本地 Whisper 模型

若您想在**完全沒有網路連接（Offline）**的電腦上使用，請依循以下步驟預先下載模型：

### 1. 下載 ONNX 模型檔案
前往 Hugging Face 下載 Xenova 轉換好的 Whisper 模型（以 `whisper-tiny` 為例）：
* 進入 [Xenova/whisper-tiny](https://huggingface.co/Xenova/whisper-tiny/tree/main) 頁面。
* 下載以下基礎設定檔：
  * `config.json`
  * `preprocessor_config.json`
  * `tokenizer.json`
  * `tokenizer_config.json` (若有)
* 進入 `onnx` 資料夾下載模型檔（推薦選擇 quantized 版本，檔案較小且速度較快）：
  * `onnx/encoder_model_quantized.onnx`
  * `onnx/decoder_model_merged_quantized.onnx`
* 將上述檔案放置在您本機的同一個資料夾中（例如建立名為 `whisper-tiny` 的資料夾，裡面包含 `config.json` 等檔案，並建立 `onnx/` 子資料夾放置 `.onnx` 檔）。

### 2. 在網頁中選取並執行
1. 在網頁的「模型來源」下拉選單中選擇 **「本機模型資料夾 (從電腦選取)」**。
2. 點選 **「選擇資料夾」** 按鈕，選取您剛剛放置模型檔案的資料夾（例如 `whisper-tiny`）。
3. 瀏覽器會跳出權限詢問，請點選「允許」以利程式讀取該目錄下的模型結構。
4. 上傳您的音訊檔，點選 **「開始語音轉文字」** 即可完成離線辨識！

## 🔒 隱私與安全性聲明
* **完全零傳輸**：除了首次從 CDN 線上加載模型（若選擇 CDN 模式）外，整個辨識、轉檔與播放流程**完全在您的瀏覽器記憶體中執行**。您可以主動拔除網路線來驗證，本程式在斷網狀態下依然可以 100% 正常辨識本地模型！
