# AetherScribe - 本地安全語音辨識與轉文字服務

AetherScribe 是一個 100% 本地運行的網頁服務。你可以開啟它來讀取 `.webm` 以及其他常見的音訊/影片檔案進行語音辨識與轉文字。

本專案的所有運算（包含格式轉檔、語音辨識）皆在本機執行，**完全不會上傳任何音訊或文字資料到外網**，確保絕對的隱私與安全性。

---

## 🌟 特色功能

1. **100% 離線與安全**：所有音訊都在本地透過 `FFmpeg` 與 `whisper-cli` 進行處理，無任何外網資料傳輸。
2. **多格式支援**：支援 WebM, WAV, MP3, MP4 等常見音訊及影片格式。
3. **模型下載與管理**：在網頁介面中即可一鍵下載與切換不同的 Whisper 模型（Tiny, Base, Small, Medium），支援續傳與取消。
4. **精準時間軸對照**：辨識完成後，可在網頁中點選字幕時間軸，播放器會自動跳轉至對應的時間進行播放，並即時高亮當前讀取段落。
5. **自動繁體中文轉換**：內建簡易簡繁轉換器，可自動將 Whisper 的簡體中文辨識結果轉換為繁體中文。
6. **多功能匯出**：一鍵複製全文、匯出為 `.txt` 檔案或標準 `.srt` 字幕檔。

---

## 🛠️ 環境需求

本專案使用以下本地工具（已檢測到您的系統已安裝）：
- **Node.js** (v22.13.1 或以上)
- **FFmpeg** (用於本地音訊格式轉檔)
- **whisper-cli** (Homebrew 安裝的 `whisper-cpp` 引擎，用於語音轉文字)

## 🚀 啟動與使用指南

### 第一步：安裝依賴套件

如果您需要重新安裝或在其他環境部署，請在專案目錄下執行：
```bash
npm install
```

### 第二步：啟動服務

在終端機中執行以下命令來啟動本機伺服器：
```bash
npm start
```
伺服器啟動後，終端機會顯示：
```
================================================================
Local Speech-to-Text Service running at http://localhost:3000
Models directory: /Users/wei-luntsou/Documents/local_web_stt/models
Temp directory: /Users/wei-luntsou/Documents/local_web_stt/temp
================================================================
```

### 第三步：開啟服務並使用

1. 打開瀏覽器，造訪 **`http://localhost:3000`**。
2. **下載模型**：首次使用時，在左側的「Whisper 模型管理」面板點擊您需要的模型旁邊的 **「下載」** 按鈕（推薦使用 **Base** 或 **Small** 模型，兼顧速度與中文辨識度）。下載進度會顯示在網頁上。
3. **設定參數**：
   - 選擇下載好的模型。
   - 語言設定為 **「中文 (Chinese)」** 或 **「自動偵測語言」**。
   - 勾選 **「自動轉換為繁體中文」**。
4. **上傳音訊/影片**：將您的 WebM、WAV 或 MP3 檔案拖放到虛線框中，或點選瀏覽選擇。
5. **開始轉換**：點擊 **「開始語音轉文字」** 按鈕。
6. **瀏覽與下載**：轉換完成後，右側將呈現時間軸段落與完整文字。您可以點選時間軸播放特定音段，或點選上方按鈕複製文字或下載 `.txt` / `.srt` 檔案。

## 🔒 隱私與網路說明
- **模型下載**：首次下載模型時，伺服器會向 Hugging Face (`https://huggingface.co`) 發送請求下載模型檔（如 `ggml-base.bin`）。
- **完全離線**：一旦模型下載完成，您可以**拔掉網路線**，服務依然可以 100% 正常運作，語音轉換過程絕不發送任何資料到外部網路。
